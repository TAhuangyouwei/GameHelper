# Max 2024 正式渲染后自动生成 MP4

适用于 F10 / Render Setup 中启用“保存文件”、输出为 AVI 的本地正式渲染。
不向 Max 的格式下拉框添加 MP4，也不改变场景、渲染器或输出设置。

## 使用

1. 将 `scripts/实用工具/动画/渲染后自动转MP4.ms` 拖入 Max 视口，或通过“脚本 → 运行脚本”加载一次。
2. F10 中照常选 AVI 输出路径、帧范围，点击渲染。
3. AVI 写入结束后后台生成同目录、同名 MP4，完成时弹窗提示。转换期间 Max 可以继续使用。

输出为 H.264 / MP4，CRF 18，兼容常见播放器；保留源视频帧率和可用音轨。
奇数宽高会在右侧或底部补最多一个像素，适配 yuv420p。
同名 MP4 已存在时生成 `_001.mp4`、`_002.mp4` 等，不覆盖已有视频。
原 AVI 始终保留；失败详情保存在 AVI 同目录的 `原文件.avi.mp4.log`。

脚本复用项目已有的 `.local/refplayer/ffmpeg.exe`，无需安装或配置 PATH；请保留完整工程目录。

已更新脚本需要在当前 Max 中重新加载一次。F11 中出现“已启用 v2”表示新版本已生效。
此版本不依赖逐帧渲染通知；转码程序等待 AVI 解除占用后检查文件是否更新，避免将未完成任何输出的旧 AVI 再次转码。
触发过程记录在 Max 的临时目录（`getDir #temp`）下的 `GameHelper-AutoMP4.log`，其中包含渲染开始、渲染结束和转换进程启动情况；完整路径会在脚本加载时显示于 F11。

## 每次启动自动启用

在 Max 用户脚本的 `startup` 文件夹中放一个 `.ms` 文件，内容为下列一行（工程移动后需更新路径）：

```maxscript
fileIn @"G:\GameHelper\scripts\实用工具\动画\渲染后自动转MP4.ms"
```

Max 2024 本机默认位置：
`%LOCALAPPDATA%\Autodesk\3dsMax\2024 - 64bit\ENU\scripts\startup`。
脚本只注册当前会话的回调，不将回调保存进 `.max` 文件；重复加载不会重复转码。

当次关闭：在 MAXScript Listener 执行 `CGH_AutoMP4.disable()`。
重新启用：执行 `CGH_AutoMP4.enable()`；永久关闭则移除上述 startup 加载文件。

## 范围与限制

- 转码也是一次有损编码，AVI 已有的压缩损失无法恢复。
- 中途取消渲染时，如果 Max 留下可读的部分 AVI，脚本可能生成对应的部分 MP4；提示表示转码成功，不代表所有计划帧均已渲染。
- 等待 MP4 完成后，再重新渲染到同一个 AVI 路径，避免转码读取期间覆盖源文件。
- 不支持 Make Preview、网络渲染、图片序列自动合成；它们不在本次功能范围。

## 验证

`python tests/unit_tests/test_render_to_mp4.py`：真实 AVI 转码、解码、帧数/帧率、音频、奇数尺寸、中文特殊字符路径、重名保护、错误日志和临时文件清理；另覆盖 AVI 未变化时跳过、无逐帧通知但 AVI 已更新时转码，以及与 Max 相同的编码命令启动方式。

在独立 Max 2024 批处理进程运行 `tests/unit_tests/test_render_to_mp4.ms`：加载与重复加载、回调注册/移除、AVI 筛选和转换程序路径，不打开或保存用户场景。

v2 已通过一次用户实际 Max 2024 F10 渲染验证：诊断日志记录渲染开始、渲染结束、转换进程自动启动，同目录生成 MP4 和成功日志，并通过 FFmpeg 完整解码检查。独立 Max 批处理测试因本机启动卡住而尚未运行完成。
