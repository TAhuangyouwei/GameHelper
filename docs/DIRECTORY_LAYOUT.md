## 约束

- `AnimTools.ms` 和 `HYW_Scripts_Library.ms` 保留在根目录，入口位置不变。
- 主面板加载的工具统一登记在 `公共模块/CGH_ToolRegistry.ms`。
- 公共模块路径登记在 `HYW_Scripts_Library.ms`；以后移动模块时也要同步修改。
- `实用工具/面部绑定/` 内的面部绑定文件必须保持在同一目录。
- `第三方工具/` 文件不做批量格式化或无关改写。
- `加密与封装工具/` 文件不作为可维护源码；来源不明的载荷不执行。
- `历史脚本/项目一次性脚本/` 文件不进入通用入口，重新使用前必须检查路径与保存行为。

## 改名后的调用检查

- 主面板加载注册表的路径、注册表中的工具路径、公共库中的模块路径和现有路径测试已同步更新。
- `加密与封装工具/SetunaConfig.xml` 中的截图程序路径已同步更新。
- 同目录加载和向上查找公共库的相对路径不受本次改名影响，因为目录层级保持不变。
- 如果 3ds Max 按钮、快捷方式或仓库外的脚本保存了旧目录的完整路径，需要在对应位置更新；仓库内无法检测这些外部配置。
- 加密脚本和封装文件内部的路径无法完整静态检查，相关工具仍需在 3ds Max 中验证。
