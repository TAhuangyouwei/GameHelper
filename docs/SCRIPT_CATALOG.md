# 脚本清单

本文记录脚本的当前角色和整理方向。“归档候选”不表示无用，只表示它依赖具体项目、路径或对象命名，不适合直接放在通用工具入口中。

状态说明：

- **入口**：用户直接运行的工具面板。
- **核心候选**：可复用代码，后续拆入公共模块。
- **工具候选**：功能较完整，适合继续维护。
- **归档候选**：一次性或项目专用脚本，先保留原样。
- **来源待确认**：尚不能确定作者、授权或当前用途。
- **第三方**：有明确外部作者或外部项目来源，后续原样放入 vendor。
- **隔离**：加密、混淆或嵌入二进制内容，不直接维护和执行。

## 已确认的作者归属

- HYW 是仓库作者本人的署名；明确标注 HYW 的脚本按自写代码维护。
- “很喜欢乱来”不是仓库作者署名；对应脚本按第三方来源管理。
